# CertPulse — Free Cloud Certification Mock Exams\n\nCertPulse is a standalone static mock-exam app for GCP Associate Cloud Engineer, Kubernetes CKA and CKAD preparation. It runs without an API key or backend, so it can be hosted for free with GitHub Pages.\n\nThis is a clean reconstruction of the CertPulse concept, not the original Emergent source export. Questions are original practice questions and are not exam dumps.\n\n## Included\n- Timed 20-question-style exam flow\n- Randomized question order\n- Score and explanations\n- Official documentation links\n- Responsive UI\n\n## Live hosting\nThe repository can be published directly with GitHub Pages.
